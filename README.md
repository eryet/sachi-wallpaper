# sachi-wallpaper
 A wallpaper with Sachi from SAO, made for Wallpaper Engine

The wallpaper includes a coordinated 20-second character loop: strong wind gusts
bend the hair and ripple the clothing, with blinking and breathing. Review [hair, face, and shirt motion](animation-preview.html)
separately or together. Wallpaper Engine exposes character animation, motion
strengths, wind gust strength, and playback speed in its settings.

The [layered SVG master](images/sachi_ai_scale.svg) retains 52 editable artwork
parts. Playback uses a cached atlas generated from that SVG. See the
[animation guide](ANIMATION.md) for controls and rebuilding, or use the
[SVG part editor](svg-preview.html) to inspect individual parts.

Use the **[layer rig editor](rig-editor.html)** for detailed animation: select
and isolate layers, adjust anchors and wind response, keyframe the loop, and
save a reusable wallpaper rig. The [rig guide](RIG.md) explains the workflow and
includes the aligned PNG and OpenRaster artwork exports.
